# 🎀 Planner Acadêmico Inteligente

Ferramenta interativa desenvolvida com auxílio do Gemini para ajudar estudantes a organizarem leituras, prazos, disciplinas e momentos de sobrecarga acadêmica.

### ✨ Principais Funcionalidades:
- 📖 Calculadora realista de tempo de leitura acadêmica.
- 🚨 Botão "Socorro Acadêmico" com plano de estudos rápido.
- ✉️ Gerador de rascunhos de e-mails para professores e orientadores.
- 🎨 Interface personalizável (upload de fotos e textos editáveis).

Feito com HTML5, Tailwind CSS e integração com a API Gemini.
